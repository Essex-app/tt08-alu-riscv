## How it works

This is an 8-bit Arithmetic Logic Unit (ALU) designed for a RISC-V processor. It supports basic arithmetic operations (addition, subtraction) and logical operations (AND, OR, XOR) based on the control signals.

## How to test

Set the input values on `ui_in` (Operand A) and `uio_in` (Operand B), then observe the output result on `uo_out`.

## External hardware

No external hardware is required.
